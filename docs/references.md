# Acknowledgements and references

This project builds on robosuite and MuJoCo for simulation, PyAV/FFmpeg and
OpenCV for video processing, NumPy/SciPy for numerical work, and Matplotlib for
figures. Thanks to the maintainers of those projects and of uv, pytest, Ruff,
ImageIO and PyYAML.

   <https://doi.org/10.1162/NECO_a_00393>
2. Y. Zhu et al., “robosuite: A Modular Simulation Framework and Benchmark for
   Robot Learning,” arXiv:2009.12293, 2020.
   <https://doi.org/10.48550/arXiv.2009.12293>

   <https://doi.org/10.1109/IROS.2012.6386109>
4. K. Cho et al., “Learning Phrase Representations using RNN Encoder–Decoder
